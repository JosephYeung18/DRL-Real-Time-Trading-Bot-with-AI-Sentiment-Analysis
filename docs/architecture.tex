# QCS - Quantitative Commodity Trading System
# 量化商品交易系统

## 项目概述

基于深度强化学习(DRL)的量化交易系统，支持EURUSD外汇和TSLA股票交易，可选择是否使用情绪增强。

**核心特性:**
- 支持真实做空交易（从零仓位开空）
- 情绪增强分析（基于新闻情绪）
- Interactive Brokers 实时交易执行
- 完整的回测和性能评估框架

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. EURUSD 回测

```bash
# 无情绪版本
python scripts/backtest_eurusd.py

# 情绪增强版本
python scripts/backtest_eurusd_sentiment.py
```

### 3. EURUSD 实时交易 (Interactive Brokers)

**前提条件:**
- Interactive Brokers TWS 或 IB Gateway
- API 端口: 7496 (Paper) 或 7497 (Live)

```bash
# Paper交易 (模拟)
python scripts/live_ib_eurusd.py --paper --duration 30

# 带情绪增强
python scripts/live_ib_eurusd.py --sentiment --duration 60
```

### 4. TSLA 回测

```bash
# 无情绪
python scripts/backtest_tsla.py

# 情绪增强
python scripts/backtest_tsla_sentiment.py --sentiment-mode 3
```

## 核心功能

### 1. EURUSD Forex交易

**自定义做空交易环境** `EURUSDShortSellingEnv`:
- 支持真正的做空交易(从零仓位开空)
- 对称的多空奖惩机制
- 杠杆/保证金管理(2x杠杆)
- 借贷成本计算

**技术指标**: MACD, Bollinger Bands, RSI, CCI, ADX, ATR, Williams %R

### 2. TSLA股票交易

基于FinRL和Lumibot的交易系统:
- A2C/PPO强化学习算法
- 三种情绪增强模式
- 完整的风险管理系统

### 3. 情绪分析

| 模式 | 数据来源 | 配置要求 |
|------|----------|---------|
| 模式1 | OpenAI API + headlines | TSLA_SEN_1.csv |
| 模式2 | Alpaca API + LLM | API Key |
| 模式3 | 预存CSV (默认，最快) | TSLA_SEN.csv |

### 4. 技术指标

| 指标 | 参数 | 说明 |
|------|------|------|
| MACD | 12,26,9 | 趋势跟踪 |
| Bollinger Bands | 20 | 波动性 |
| RSI | 14 | 超买超卖 |
| CCI | 14 | 顺势指标 |
| ADX | 14 | 趋势强度 |
| ATR | 14 | 真实波幅 |
| Williams %R | 14 | 超买超卖 |
| 情绪分数 | -1 to +1 | 新闻情绪 |

## 注意事项

1. EURUSD回测使用自定义环境，需使用 `scripts/backtest_eurusd.py`
2. EURUSD实时交易使用 `scripts/live_ib_eurusd.py` (需IB)
3. TSLA回测使用 `scripts/backtest_tsla.py` 或 `scripts/backtest_tsla_sentiment.py`
4. 实时交易需要设置相应API密钥
5. 过去表现不代表未来收益
